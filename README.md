# 32 張配對翻牌遊戲

一個可直接部署至 GitHub Pages 的單檔翻牌網站，包含 32 張固定配對卡片、3D 翻牌動畫、翻牌計數與重新開始功能。

## 修改卡片

開啟 `index.html`，編輯其中的 `cards` 陣列。每組資料的第一項是正面文字，第二項是背面文字：

```js
const cards = [
  ["正面文字", "背面文字"]
];
```

儲存並推送至 `main` 分支後，GitHub Pages 會自動更新。

## 使用方式

1. 點擊任一張尚未翻開的卡片。
2. 翻開後查看背面的配對文字；同一張卡不能再次操作。
3. 下方計數器會顯示已翻牌數量。
4. 點擊「重新開始」即可恢復全部卡片。

## 本機預覽

這是零依賴靜態網站，可直接開啟 `index.html`，或在資料夾執行任一靜態伺服器。
