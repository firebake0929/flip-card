# 東華臺灣文化系｜直屬抽籤翻牌網站

一個可直接部署至 GitHub Pages 的單頁抽籤網站，支援手機與電腦，包含 3D 翻牌、隨機抽取、避免同一輪重複與彩紙動畫。

## 修改抽籤名單

開啟 `script.js`，編輯最上方的 `seniors` 陣列：

```js
const seniors = ["學長姐一", "學長姐二", "學長姐三"];
```

儲存並推送至 `main` 分支後，GitHub Pages 會自動更新。

## 使用方式

1. 點擊卡片翻牌。
2. 查看抽出的直屬姓名。
3. 點擊「再抽一張」回到牌面，交給下一位抽取。
4. 每一輪同一個名字只會出現一次；全部抽完後會自動開始新一輪。
5. 如需立即重新開始，點擊頁面底部「重置所有抽籤紀錄」。

## 本機預覽

這是零依賴靜態網站，可直接開啟 `index.html`，或在資料夾執行任一靜態伺服器。
